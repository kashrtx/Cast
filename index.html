Running the AI on your own computer

Ollama and LM Studio run a model on your own computer. Free, private, and no key needed. Pick one of them as the provider above.

On the same computer

Nothing to set up. Start Ollama or LM Studio and press Check the connection. If it fails, Ollama needs the environment variable OLLAMA_ORIGINS=* before it will accept requests from a browser. LM Studio accepts them already.

From your phone, to a model on your computer

This needs a helper, because a web page is not allowed to reach across your network on its own. It only works in a browser that supports extensions, which means Orion on iOS, or Firefox, Orion or Edge Canary on Android. Safari and Chrome on mobile cannot do it.

  1. Install Tampermonkey in that browser
  2. Install the Cast Local AI Bridge script
  3. Keep the phone and the computer on the same wifi
  4. Start Ollama or LM Studio so it listens on your network, not only on localhost
  5. Set the address above to your computer's address, such as http://192.168.1.25:11434, because on a phone localhost means the phone

If none of this appeals, the hosted providers above need nothing installed and several are free.
